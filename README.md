# incident-tracker-angular

Sistema web desarrollado en Angular para registrar, clasificar y dar seguimiento a incidentes técnicos usando GitHub Issues y Projects.

## Flujo de trabajo
1. Detectar incidente
2. Crear issue
3. Clasificar
4. Asignar responsable
5. Mover en el tablero
6. Corregir en Angular
7. Registrar evidencia
8. Cerrar issue
